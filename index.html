🔑 One-Time Setup
You need a free YouTube API key. Takes 2 minutes. Free forever (100 searches/day).
HOW TO GET YOUR FREE KEY
1
Go to console.cloud.google.com → Sign in with Google
2
Click Select a project → New Project → name it anything → Create
3
Go to APIs & Services → Library → search "YouTube Data API v3" → Enable it
4
Go to APIs & Services → Credentials → Create Credentials → API Key
5
✅ Copy the key → paste below → done!
💡 Completely free: 10,000 units/day. Each search = 100 units = 100 searches/day free. No credit card needed.
Key is saved only in your browser — never shared
🚀 Deploy Your App
Two ways to go live — both 100% free, no credit card
OPTION A — Netlify Drop  ⚡ Fastest (30 seconds)
1
Go to app.netlify.com/drop in your browser
2
Download this HTML file → drag and drop it onto the page
3
✅ Done! You get a free URL like random-name.netlify.app
OPTION B — Vercel  (Best for custom domains)
1
Sign up free at vercel.com
2
Click Add New → Project → upload the HTML file (rename to index.html)
3
Hit Deploy → live in ~60 sec at yourname.vercel.app
OPTION C — GitHub Pages (Free forever + version control)
1
Create a free GitHub account → New repo → upload file as index.html
2
Repo Settings → Pages → Source: main branch → Save
3
✅ Live at username.github.io/reponame
→ Open Netlify Drop Now (Recommended)
All options are permanently free for static HTML sites
